How your data is protected

  • Supabase Row Level Security restricts the cloud record to your signed-in account.
  • The secret database key and database password are never stored in the website.
  • A local backup is created before cloud data replaces the current browser data.
  • Realtime synchronization receives changes made on another signed-in device.
